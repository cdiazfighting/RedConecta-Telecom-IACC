
# Análisis de datos - RedConecta Telecom

## Descripción

Este proyecto corresponde a la tarea de la semana 8
de Ciencia de Datos de IACC.

Se analiza la información operacional de la empresa
RedConecta Telecom S. A. mediante Python.

## Objetivo

Analizar la latencia, incidencias, tiempos de resolución
y cumplimiento de SLA para identificar posibles
problemas en la calidad del servicio.

## Herramientas utilizadas

- Python
- Pandas
- Matplotlib
- OpenPyXL
- Git

## Archivos principales

- dataset_set_D_telecomunicaciones.xlsx
- analisis_redconecta.py
- dashboard_redconecta.png
- reporte_soporte_tecnico.xlsx
- reporte_experiencia_clientes.xlsx

## Ejecución

Instalar las librerías necesarias:

pip install pandas openpyxl matplotlib

Ejecutar el programa:

python analisis_redconecta.py

## Resultados iniciales

La región Sur registra 999 incidencias.
El servicio Móvil presenta un tiempo promedio de
resolución de 26,28 horas.

De los 200 registros, el 52 % no cumple el SLA.

## Observación

Los resultados corresponden al dataset entregado
para la actividad académica.
